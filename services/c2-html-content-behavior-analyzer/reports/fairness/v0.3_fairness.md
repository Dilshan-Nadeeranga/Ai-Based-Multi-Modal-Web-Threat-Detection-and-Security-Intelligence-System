# Fairness of the verdict on benign pages - v0.3

Benign false-positive rate per subgroup at the live operating points (arms: dom, behavior, text_tfidf, text_xlmr; thresholds {'arms': 'dom+behavior+text_tfidf+text_xlmr', 'malicious_below_p_benign': 0.182466, 'suspicious_below_p_benign': 0.511482, 'malicious_min_risk': 82, 'suspicious_min_risk': 49}). Suspicious-or-worse = the 'check first' band, Malicious = the ≤ 2 % OOF FPR cut-off; the evidence floor is applied. OOF = 391 train+val pages (where the thresholds were fitted - design numbers); test = 68 held-out pages. Wilson 95 % CIs; Fisher exact test vs the reference group. **Small n: one page moves a small group's rate by 10-25 points.**

## Tagging rule

```text (benign pages only, metadata.csv of the frozen version):
- ``lk_sme``   notes match SME / "local company|business|shop|cafe|retail|boutique|
               bookstore|handloom" (the collector's own description of small LK businesses)
- ``lk_other`` not lk_sme, and the registrable domain of source_url or final_url ends in
               ``.lk`` or the notes mention Sri Lanka / "local"
- ``non_lk``   everything else
``lk_all`` = lk_sme + lk_other. Language = metadata language AND the Part 5A detected page
language.
```
