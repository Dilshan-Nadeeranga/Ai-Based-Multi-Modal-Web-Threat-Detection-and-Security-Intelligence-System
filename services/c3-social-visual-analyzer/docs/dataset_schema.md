# ScamTrace C3 – Multimodal Dataset Schema (v0.1)

This document describes how one **dataset sample** (a social-media post or web
item) is stored by the C3 Social Media & Web Visual Threat Analyzer. Label
meanings are documented separately in [`dataset_labels.md`](dataset_labels.md).

The schema is enforced in code by `app/schemas/dataset_schema.py` (Pydantic) and
checked on disk by `scripts/validate_dataset.py`.

## 1. Sample ID

| Rule | Value |
| --- | --- |
| Format | `SVT_` + 6 digits, e.g. `SVT_000001` |
| Regex | `^SVT_[0-9]{6}$` (`SVT_000000` is not allowed) |
| Meaning | Opaque identifier. It does **not** encode the label, platform or brand. |
| Allocation | Highest existing number + 1. Numbers are never reused, even after gaps. |
| Uniqueness | Checked against `dataset_metadata.jsonl` **and** the file names already present in `data/raw/images/`, `data/raw/posts/` and `data/webpage_screenshots/`. Allocation runs under a cross-process lock (`data/annotations/.dataset.lock`). |

`SVT` stands for **S**ocial **V**isual **T**hreat. The ID is label-independent so
that a sample can be relabelled without being renamed.

## 2. File naming

| Evidence | Folder | Name |
| --- | --- | --- |
| Post image *n* | `data/raw/images/` | `SVT_000001_01.jpg`, `SVT_000001_02.png`, … |
| Raw post snapshot | `data/raw/posts/` | `SVT_000001.json` |
| Webpage screenshot *n* (future) | `data/webpage_screenshots/` | `SVT_000001_web_01.png` |
| Phase 1 preprocessing upload | `data/raw/uploads/` | `<sample_id>_<random>.ext` |
| Phase 1 processed image | `data/processed/images/` | `<sample_id>_<random>.png` |

* Image numbers start at `01` and are sequential, in the order supplied.
* The extension comes from the **real image format** detected by Pillow
  (JPEG → `.jpg`, PNG → `.png`, WEBP → `.webp`), never from the client file name.
* Original image bytes are stored unchanged (no resizing, no re-encoding).
* Client file names never become storage paths; the original name is kept only
  as metadata in the raw post snapshot.

## 3. Folder layout

```text
data/
├── raw/
│   ├── images/              dataset evidence images (SVT_xxxxxx_NN.ext)
│   ├── posts/               raw post snapshots (SVT_xxxxxx.json)
│   └── uploads/             Phase 1 /preprocess-image uploads
├── processed/
│   └── images/              Phase 1 normalized PNGs
├── rejected/                Phase 1 rejected uploads
├── webpage_screenshots/     reserved for destination screenshots (future card)
├── annotations/
│   ├── dataset_metadata.jsonl   one dataset sample per line   (this schema)
│   ├── labels.jsonl             label history, one event per line
│   ├── ocr_results.jsonl        Phase 1 OCR results (unchanged)
│   └── image_hashes.json        Phase 1 pHash store (unchanged)
└── statistics/
    └── dataset_statistics.json  generated by scripts/generate_statistics.py
```

All record paths are written as `data/...` relative to the configured data
directory, using forward slashes, so records stay valid on Windows and Linux and
when the data folder is copied elsewhere (`DATA_DIR` / `--data-dir`).

## 4. `dataset_metadata.jsonl` record

One UTF-8 JSON object per line. Lines are only ever **appended**; existing lines
are never rewritten by the tools. Example (synthetic, `example.invalid`):

```json
{
  "sample_id": "SVT_000002",
  "dataset_version": "0.1",
  "source": {
    "platform": "facebook",
    "source_url": null,
    "collection_method": "synthetic_test",
    "collected_at": "2026-10-08T18:09:45Z",
    "source_dataset": null,
    "source_reference": null
  },
  "post": {
    "text": "Verify your example account immediately",
    "images": ["data/raw/images/SVT_000002_01.jpg"],
    "embedded_urls": ["https://example.invalid/login"],
    "raw_snapshot": "data/raw/posts/SVT_000002.json"
  },
  "ocr": { "completed": false, "text": null, "average_confidence": null },
  "brand": { "claimed_brand": "ExampleBrand", "detected_brand": null, "confidence": null },
  "destination": {
    "original_url": "https://example.invalid/login",
    "final_url": null,
    "domain": null,
    "screenshots": []
  },
  "labels": {
    "is_scam": 1,
    "scam_type": "brand_impersonation",
    "label_status": "verified",
    "notes": null,
    "misinformation": {
      "is_fake": null,
      "misinfo_type": "unknown",
      "label_status": "not_annotated",
      "source_label": null
    }
  },
  "processing": { "preprocessed": false, "ocr_completed": false, "webpage_captured": false },
  "created_at": "2026-10-08T18:09:45Z",
  "updated_at": "2026-10-08T18:09:45Z"
}
```

### Field reference

| Field | Type | Required | Notes |
| --- | --- | --- | --- |
| `sample_id` | string | yes | See §1. |
| `dataset_version` | string | yes | `major.minor[.patch]`, from `DATASET_VERSION`. |
| `source.platform` | enum | yes | `facebook`, `instagram`, `x`, `tiktok`, `youtube`, `linkedin`, `telegram`, `whatsapp`, `reddit`, `website`, `other`, `unknown`. |
| `source.source_url` | URL \| null | no | Public URL of the post, if any. http/https only. |
| `source.collection_method` | enum | yes | `manual`, `public_dataset`, `api`, `research_archive`, `synthetic_test`. |
| `source.collected_at` | UTC timestamp | yes | ISO 8601 with `Z`. Defaults to the time of import. |
| `source.source_dataset` | string \| null | no | Name of a public dataset the sample came from. |
| `source.source_reference` | string \| null | no | ID/reference within that dataset or archive. |
| `post.text` | string \| null | * | Post caption/body. Whitespace-normalized; blank becomes null. |
| `post.images` | list of paths | * | `data/raw/images/{sample_id}_NN.(jpg\|jpeg\|png\|webp)`, sequential from `01`, no duplicates. |
| `post.embedded_urls` | list of URLs | no | http/https with a host, ≤ 2048 chars, no whitespace, no duplicates. May be empty. |
| `post.raw_snapshot` | path \| null | no | Must be `data/raw/posts/{sample_id}.json` when present. |
| `ocr.*` | object | yes | Filled by a later card (OCR on dataset images). `average_confidence` is 0–100. |
| `brand.claimed_brand` | string \| null | no | Brand the post *claims* to be (annotator input). |
| `brand.detected_brand`, `brand.confidence` | | no | Reserved for future brand detection; confidence 0–1. |
| `destination.original_url` | URL \| null | no | First embedded URL; must appear in `post.embedded_urls`. |
| `destination.final_url`, `domain`, `screenshots` | | no | Reserved for the webpage capture card. Screenshot paths follow §2. |
| `labels.is_scam`, `scam_type`, `label_status`, `notes` | | yes | Scam task. See [`dataset_labels.md`](dataset_labels.md). `label_status` may be `not_annotated`. |
| `labels.misinformation` | object | no | Fake-news task: `is_fake`, `misinfo_type`, `label_status`, `source_label`. Defaults to `not_annotated`. At least one of the two tasks must be annotated. |
| `processing.*` | booleans | yes | `ocr_completed` must equal `ocr.completed`; `webpage_captured` requires at least one screenshot. |
| `created_at`, `updated_at` | UTC timestamps | yes | `updated_at >= created_at`. |

\* A sample needs **post text, at least one image, or both**.

Unknown extra fields are preserved on read (`extra="allow"`), so later cards can
add fields without breaking older readers.

### Linking text + image + URL

The `sample_id` is the join key across every artefact:

* `post.text`, `post.images` and `post.embedded_urls` live in the same record;
* images are named `{sample_id}_NN.ext`;
* the raw snapshot is `data/raw/posts/{sample_id}.json` and stores each image's
  stored path, original file name and SHA-256;
* `labels.jsonl` events carry the same `sample_id`;
* Phase 1 OCR can be run per image with `sample_id=SVT_000001_01`, so
  `ocr_results.jsonl` rows join back to the dataset sample.

## 5. `labels.jsonl` event

```json
{"sample_id":"SVT_000002","is_scam":1,"scam_type":"brand_impersonation","label_status":"verified","notes":null,"event":"initial_label","labelled_at":"2026-10-08T18:09:45Z"}
```

Every created sample gets one `initial_label` event. The file is an append-only
history, so future relabelling can add new events without editing old ones. The
validator warns if the latest event for a sample disagrees with its record.

## 6. Raw post snapshot (`data/raw/posts/SVT_xxxxxx.json`)

An immutable copy of what the annotator supplied at import time:
`sample_id`, `captured_at`, `platform`, `source_url`, `collection_method`,
`post_text`, `embedded_urls`, `claimed_brand`, and `images[]` with
`stored_path`, `original_filename` and `sha256`. It contains no personal data
(no account names, profiles, comments, phone numbers or messages).

## 7. Validation

`python scripts/validate_dataset.py` reports findings with these codes:

| Severity | Codes |
| --- | --- |
| error | `INVALID_JSONL`, `REQUIRED_FIELD_MISSING`, `INVALID_LABEL`, `LABEL_INCONSISTENT`, `INVALID_PLATFORM`, `INVALID_SAMPLE_ID`, `INVALID_URL`, `INVALID_IMAGE_PATH`, `SCHEMA_ERROR`, `DUPLICATE_SAMPLE_ID`, `DUPLICATE_IMAGE_PATH`, `UNSAFE_PATH`, `IMAGE_MISSING`, `IMAGE_INVALID`, `SCREENSHOT_MISSING`, `INVALID_LABEL_JSONL`, `LABEL_ORPHAN` |
| warning | `METADATA_MISSING`, `SNAPSHOT_MISSING`, `VERSION_MISMATCH`, `SYNTHETIC_SAMPLE`, `LABEL_EVENT_MISSING`, `LABEL_MISMATCH`, `ORPHAN_IMAGE_FILE` |

The exit code is `0` when there are no errors and `1` otherwise.

## 8. Statistics

`python scripts/generate_statistics.py` reads only `dataset_metadata.jsonl` and
writes `data/statistics/dataset_statistics.json`. Every number is counted from
schema-valid records; invalid records and malformed lines are skipped and
reported (`skipped_invalid_records`, `malformed_lines`). `synthetic_test`
samples are excluded unless `--include-synthetic` is given, and the count of
excluded samples is reported.
